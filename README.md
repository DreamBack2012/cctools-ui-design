# CCTools 界面与交互设计

面向多设备操作的 CCTools 界面与架构设计。设备工作台统一选择目标，直接发起配置、OTA、导出等操作，任务中心统一展示结果。

本工程使用模拟数据，不连接真实设备。网页用于设计评审，正式工具仍采用 Qt Widgets。业务字段和限制见[现有功能对应表](docs/现有功能对应表.md)。

## 本地运行

安装 Node.js 22 或更新版本后，在工程根目录执行：

```bash
npm start
```

浏览器访问 <http://localhost:4173>。运行原型不需要安装 npm 依赖；停止时在启动终端按 Ctrl+C。

如果工程运行在远程服务器或容器内，可以通过 SSH 将端口转发到本机：

```bash
ssh -N -L 4173:127.0.0.1:4173 -p <SSH端口> <用户名>@<服务器地址>
```

然后在本机浏览器访问相同地址。SSH 地址和端口使用平时登录开发环境的配置。
也可以在 VS Code“端口”面板转发 4173。

默认服务端口为 4173，绑定地址可通过 `HOST`、端口可通过 `PORT` 环境变量配置。
本地预览默认绑定回环地址；只有确实需要局域网访问时才指定其他绑定地址。

## 设计边界

界面按 Qt 5.14.2 / Qt Widgets 桌面程序设计。浏览器仅承载预览，正式实现不依赖 Web 服务。
页面上展示的是计划实现的产品控件；原型限制和测试入口仅在本文说明。

主窗口采用固定导航、设备列表、页签操作区、底部执行结果与状态栏。列表与操作区、工作区与结果区均可拖动分隔条调整大小。
配置、OTA、设备管理和任务详情在主窗口内完成；对话框用于属性设置、文件选择与必要确认。
Qt 控件映射与实现约束见 [架构设计](docs/架构设计.md)。

## 建议体验顺序

1. 局域网与云端设备通过页签分别查看；工具栏直接编辑完整起止 IP，两端的第三、第四段均独立可编辑（如 192.168.18.1～192.168.19.254）。
2. 在设备工作台勾选三台已连接的 CT15 设备，切换右侧“配置导入”页签。
3. 点击“选择文件”，选择下方的 CT15 配置文件，在同一页签检查参数变更，点击执行。
4. 在底部结果区查看逐台进度、错误和日志；切换页面后任务继续执行，无需进入任务中心。
5. 同时选中不同型号，体验能力检查；“逐台分配”可分别指定对应型号的配置文件。
6. 点击左侧设备名称，在右侧“设备管理”中查看概览、参数、终端和文件。
7. 固件烧录中选择产品、部件、接口和文件，再创建任务。
8. 在工厂版预览中启动 PCBA 测试，等待 LED 人工确认。

浏览器原型中的设备、文件列表和运行结果均为模拟数据，刷新后恢复初始状态。
实际硬件、驱动、云服务及设备持久化配置未在本工程实现。仅搜索范围保存在浏览器本机存储中，不保存真实凭据。

## 预览文件与场景

- [CT15 参数配置](docs/fixtures/CT15_参数配置.xlsx)
- [CT13 参数配置](docs/fixtures/CT13_参数配置.xlsx)

将 Excel 配置文件保存到本机后，从界面选择导入。工作表、参数列和 SN 行结构与现有工具一致；
浏览器借助本地 SheetJS 读写，正式 Qt 工具继续使用 QXlsx，不引入新的产品文件格式。
旧 JSON 文件不作为产品配置文件；界面与回归测试均使用 Excel。
固件选择只读取文件名，不解析、传输或烧录实际固件。

版本视角通过地址参数预览，正式软件仍通过构建版本决定功能，没有运行时版本切换控件：

- 内测版：<http://localhost:4173/>
- 发行版：<http://localhost:4173/?edition=release>
- 工厂版：<http://localhost:4173/?edition=factory>
- 部分失败场景：<http://localhost:4173/?scenario=failure>，发起批量操作后最后一台失败，可体验失败重试。

顶部版本切换会重新加载对应预览，当前模拟任务和未保存输入会清空。以上工具条及 URL 参数仅用于评审和自动测试，不属于待实现的正式功能。

## 验证

```bash
npm run check
npm test
```

浏览器回归需要安装开发依赖与 Chromium：

```bash
npm install
npm run lint
npx playwright install chromium
npm run test:browser
```

执行浏览器回归前保持 `npm start` 运行。浏览器测试会检查批量导入、失败重试、能力检查、型号校验、
LED 确认、搜索范围校验、型号烧录映射、Excel 导入校验、页签输入保留、非模态操作和可调整分栏；截图写入被 Git 忽略的 `artifacts/`。
